# docs/architecture

Architecture documentation for QualiOS AI — the plan of record under the Complete Master Blueprint v1.0 (20 November 2026).

- `ARCHITECTURE.md` — target architecture: modular monolith, stack, tenancy/isolation, core services, AI, delivery. Includes §1A: the industry-neutral core rule (hard constraint, 20 Nov 2026).
- `DATA_MODEL.md` — data model: implemented entities, planned entities (subscriptions, invites, SOP publish, training), conventions, and the industry-pack extension pattern.
- `DECISIONS.md` — the 13 ADRs carried forward from the v1.0 record (with status), the open decisions needing Devon's call, and the decisions made in this revision.

The old v1.0 architecture docs (ADR record, wedge data model) remain in the project workspace under `~/workspace/goals/qualios-ai-cannabis-platform/files/` for history. They are **superseded** as the plan of record. The current-state audit (`QualiOS-Current-State-Audit-2026-11-20.md`, same folder) is the evidence base for these docs.

Planning only: nothing in these docs is built unless the audit says it is.
